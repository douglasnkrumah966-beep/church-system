1. Introduction

The Church Management System is a complete, mobile-friendly platform designed to serve the administrative needs of a Roman Catholic parish station.

Purpose

This system helps the parish office, secretary, finance officer, catechist, and priest manage:

  • Members — registration, photos, contact details
  • Sacraments — Baptism, First Holy Communion, Confirmation, Marriage
  • Day Born Groups — Sunday Born through Saturday Born
  • Attendance — catechism and parish events
  • Finance — collections, contributions, expenses, cashbook
  • Communication — WhatsApp groups and bulk messaging

Key Features

  • ✅ Multi-role access with distinct dashboards
  • ✅ Mobile-friendly interface — works on phones, tablets, and computers
  • ✅ Ghana Cedis (GH₵) as the default currency
  • ✅ Timezone set to Africa/Accra
  • ✅ Member photos with upload support
  • ✅ Automated login creation for new members
  • ✅ Cashbook with running balance
  • ✅ Funeral contribution tracking with WhatsApp thank-you
  • ✅ Backup and restore functionality
  • ✅ Activity logs for auditing
  • ✅ Maintenance mode for safe updates

2. System Overview

The system is divided into five independent areas, each with its own color theme and menu. Each user is assigned to a single role and only sees their own area.

Area Color Icon Purpose
System Admin Navy 🔧 Technical management only
Station Admin Purple ✝️ Full church operations
Secretary Blue ✍️ Members, sacraments, attendance
Finance Officer Green 💰 Collections, expenses, reports
Catechist Orange 📖 Sacraments and attendance
Member Purple 🙏 Personal portal

How It Works

  1. User opens the login page
  2. Enters their username and password
  3. System checks credentials against the users table
  4. User is redirected to their role-specific dashboard
  5. Menu options change based on role
  6. All actions are logged in activity_logs
Simple for everyone Members log in with their phone number as username. Staff use simple names like secretary or finance. Everyone sees only what they need.

3. User Roles & Access

🔧 System Administrator

Purpose: Technical management only — never touches church operations.

Can access:

  • User accounts, roles, permissions
  • Security settings, backups
  • Database browser, system logs
  • Activity logs, settings, maintenance mode

Cannot access: Members, Sacraments, Finance, Reports, WhatsApp

✝️ Station Administrator

Purpose: Parish leadership (usually the priest).

Can access: Everything except technical pages.

✍️ Station Secretary

Purpose: Parish records.

Can access:

  • Members — register, edit, view cards
  • Sacraments — record
  • Day Born dashboards
  • Attendance & reports
  • WhatsApp groups & bulk messages

💰 Finance Officer

Purpose: Money management.

Can access:

  • First Collection, Day Born Collection
  • Contributions (with funeral support)
  • Expenses
  • Cashbook
  • Funeral Report, Reports, Financial Settings

📖 Catechist

Purpose: Faith formation.

Can access:

  • Sacraments
  • Members (view only)
  • Attendance & reports
  • WhatsApp groups

🙏 Member

Purpose: Personal access.

Can access:

  • Own profile and photo
  • Own sacraments and giving history
  • View own Day Born group only

4. Installation Guide

Step 1 — Install XAMPP

  1. Download XAMPP from apachefriends.org
  2. Install to C:\xampp\ (default)
  3. Open XAMPP Control Panel
  4. Click Start next to Apache and MySQL
  5. Both should show green — meaning they're running

Step 2 — Copy Project Files

Copy the entire chruch_system folder to:

C:\xampp\htdocs\chruch_system\

Verify the folder exists with login.php inside:

dir C:\xampp\htdocs\chruch_system\login.php

Step 3 — Create the Database

  1. Open http://localhost/phpmyadmin
  2. Click New on the left
  3. Database name: church_db
  4. Collation: utf8mb4_general_ci
  5. Click Create
  6. Click the Import tab
  7. Choose file: database.sql
  8. Click Go

Step 4 — Configure Database Connection

Open config/database.php and verify:

$DB_HOST = 'localhost';
$DB_NAME = 'church_db';
$DB_USER = 'root';
$DB_PASS = '';

Step 5 — Reset Admin Passwords (one time)

Create reset_admin.php in the project root:

<?php
require_once 'config/database.php';
$hash = password_hash('password@123', PASSWORD_DEFAULT);
$pdo->prepare("UPDATE users SET password = ?")->execute([$hash]);
echo "All passwords reset to password@123";

Open http://localhost/chruch_system/reset_admin.php, then delete the file.

Step 6 — Create Upload Folders

mkdir C:\xampp\htdocs\chruch_system\uploads\members
mkdir C:\xampp\htdocs\chruch_system\backups

Step 7 — Test the Login

Open:

http://localhost/chruch_system/login.php

Log in as admin / password@123

⚠️ Important After logging in successfully, immediately change the admin password via My Password. Write the new password down and store it safely.

8. Admin Guide (System Administrator)

Dashboard

Shows system health at a glance:

  • User accounts, system admins, database tables
  • System errors, database size, backups, 24h activity
  • Server info (PHP version, disk space, timezone)

Users

Create and manage all user accounts.

  1. Click Admin → Users
  2. Fill in Full Name, Username, Password, Role
  3. Click Create User

To reset a password: click the 🔑 button next to any user.

Roles & Permissions

  • Roles — View the 6 built-in roles + add custom roles
  • Permissions — Assign fine-grained permissions per role

Security

  • Minimum password length (recommended: 8)
  • Require numbers (recommended: Yes)
  • Require symbols (optional)
  • Max login attempts (recommended: 5)
  • Session timeout (recommended: 120 minutes)
  • Force HTTPS (only if SSL certificate installed)

Database Browser

Read-only view of all tables. You can:

  • Browse each table's rows (max 50)
  • Export any table as CSV
  • Verify data was saved correctly

Backups

  1. Click 💾 Create Backup
  2. Wait for confirmation
  3. Click the ⬇ download button
  4. Save the SQL file somewhere safe

System Logs & Activity Logs

  • System Logs — technical errors, warnings, info messages
  • Activity Logs — every user action with time, user, IP

Settings

  • Church name (shown in headers and printed documents)
  • Currency symbol (default: GH₵)
  • Timezone (default: Africa/Accra)

Maintenance Mode

Temporarily block non-admin users during updates:

  1. Toggle Enable Maintenance Mode ON
  2. Choose allowed roles (sysadmin always allowed)
  3. Customize the message shown to blocked users
  4. Click Save

9. Secretary Guide

Registering a New Member

  1. Click Members in the menu
  2. Fill in the registration form:
    • Full Name (required)
    • Phone Number (required — becomes their login)
    • Gender, Marital Status, Baptism
    • Date of Birth — choose from:
      • Full date — auto-calculates Day Born
      • Year only — for older members
      • Approximate age — if only age is known
      • Not known — with manual Day Born selection
    • Photo (optional, max 3 MB)
  3. Click Save Member & Create Login
✅ Login auto-created The member can now log in with their phone number and the default password password@123.

Recording a Sacrament

  1. Click Sacraments
  2. Select the member
  3. Choose sacrament type (Baptism, Communion, Confirmation, etc.)
  4. Enter date, minister, place, certificate number
  5. Click Save

Day Born Dashboard

Seven colorful tiles (Sunday Born through Saturday Born). Tap any group to see all members born on that day. Members with the same day born celebrate their birthdays together.

Marking Attendance

  1. Click Attendance
  2. Create a session (title, date, category)
  3. For each member, tap ✓ Present or 🕊 Excused
  4. Click 💾 Save Attendance

Attendance Report

Shows attendance rate for each member with a color-coded bar:

  • Green ≥ 75% — excellent attendance
  • Amber 50–74% — moderate
  • Red < 50% — needs follow-up

Member ID Card

  1. Find the member in the Members list
  2. Click the 🪪 card icon
  3. Click 🖨 Print / Save as PDF

WhatsApp Groups

  1. Create the group in WhatsApp first
  2. Copy the invite link
  3. In the system, go to WhatsApp Groups
  4. Paste the link and save
  5. Click 💬 Invite next to each member to send them the link

Bulk Messages

  1. Click Bulk Message
  2. Choose audience (all members, birthdays today, or a Day Born group)
  3. Type your message or pick a template
  4. Click Load Recipients
  5. Send to each member with 💬 or copy the phone list for SMS

10. Finance Officer Guide

Dashboard

  • Total Income, Total Expenses, Balance
  • This Month and This Year snapshots
  • 6-month bar chart (income vs. expenses)
  • Category totals and recent transactions

First Collection

  1. Click First Collection
  2. Type the collection name (e.g. "First Collection — 8am Mass")
  3. Enter amount, date, status
  4. Click Save Record

Mark as Deposited once the money is banked.

Day Born Collection

  1. Click Day Born Collection
  2. Pick a Day Born Group (Sunday Born, Monday Born, etc.)
  3. Enter amount, date, status
  4. Click Save Record

Contributions

Nine contribution types are available:

  1. Thanksgiving Offering
  2. Harvest Contribution
  3. Welfare Contribution
  4. Building Fund
  5. Donation
  6. Funeral Contribution
  7. Fundraising
  8. Special Appeal
  9. Other Contribution

Each contribution is linked to a member. The system auto-generates a receipt.

Funeral Contributions

When you select Funeral Contribution, extra fields appear:

  • Contributing For — name of the deceased
  • Relationship — Father, Mother, Brother, etc.
  • Payment Method — Cash, Mobile Money, etc.

After saving, open Funeral Report to see all contributions for a deceased and send WhatsApp thank-you messages.

Expenses

17 categories: Electricity, Water, Church Maintenance, Cleaning, Stationery, Transportation, Communication, Catechetical Activities, Liturgical Items, Pastoral Activities, Funeral Expenses, Repairs, Salaries / Allowances, Welfare, Events, Bank Charges, Other Expense.

Cashbook

The central financial ledger. Automatically pulls from:

  • First Collection
  • Day Born Collection
  • Contributions
  • Expenses

Shows Opening Balance, all transactions with running balance, and Closing Balance.

Reports

  1. Pick a date range
  2. Optionally filter by type, category, or member
  3. Click Generate Report
  4. Click 🖨 Print / Save as PDF for a formal report

Shows members, sacraments, catechism sessions, today's birthdays, recent sacraments, and upcoming birthdays this week.

13. Backup & Recovery

Why Backups Matter

Backups protect the parish records against:

  • Accidental deletion
  • Computer failure
  • Virus or ransomware
  • Power outage during a write
  • Human error

Creating a Backup

  1. Log in as sysadmin
  2. Click Admin → Backups
  3. Click 💾 Create Backup
  4. Wait for the confirmation message
  5. Click the ⬇ download button
  6. Save the SQL file to your computer

Backup Retention — Best Practice

FrequencyKeepStore
Daily7 daysServer's /backups/ folder
Weekly4 weeksExternal drive
Monthly12 monthsCloud (Google Drive, Dropbox)

Restoring from a Backup

If the database is corrupted or lost:

  1. Open http://localhost/phpmyadmin
  2. Click on church_db on the left
  3. Click the Import tab
  4. Choose the backup .sql file
  5. Click Go
  6. Log back in to the system
⚠️ Before Restoring Restoring overwrites the live database. Any data added since the backup was made will be lost. Only restore when absolutely necessary.

Automated Backups (Optional)

On Windows, use Task Scheduler to run this command daily:

"C:\xampp\mysql\bin\mysqldump.exe" -u root church_db > "D:\Backups\church_%date:~10,4%-%date:~4,2%-%date:~7,2%.sql"

Emergency Recovery

If you lose the sysadmin password:

  1. Create reset_admin.php in the root: 
    <?php
require_once 'config/database.php';
$hash = password_hash('password@123', PASSWORD_DEFAULT);
$pdo->prepare("UPDATE users SET password = ? WHERE username = 'admin'")->execute([$hash]);
echo "Reset complete";
  2. Open http://localhost/chruch_system/reset_admin.php
  3. Log in with admin / password@123
  4. Delete the file immediately

14. Maintenance Mode

What It Does

Maintenance mode temporarily blocks all users except those you choose. It's used when:

  • Making database updates
  • Taking a full backup
  • Fixing critical bugs
  • Performing system migrations
  • Training new staff

Enabling Maintenance Mode

  1. Log in as sysadmin
  2. Click Admin → Maintenance
  3. Toggle Enable Maintenance Mode ON
  4. Select which roles can still access (Sysadmin is always allowed)
  5. Customize the message shown to blocked users
  6. Click 💾 Save

What Blocked Users See

A clean page with the church name, an icon, and your custom message — for example:

🛠
Roman Catholic Church
System is under maintenance.
Please check back shortly.

Disabling Maintenance Mode

  1. Log in as sysadmin
  2. Go to Admin → Maintenance
  3. Toggle OFF
  4. Click Save
⚠️ Remember to Turn It Off If you forget, parishioners cannot access the system. Check the status banner at the top of the maintenance page — it shows ON or OFF clearly.

How It Works Behind the Scenes

Every page load checks the maintenance_mode table:

  1. If maintenance is OFF → normal access
  2. If maintenance is ON:
    • Sysadmin always allowed
    • If the user's role is in the allowed list → normal access
    • Otherwise → redirected to maintenance_page.php

15. Troubleshooting

Login Issues

ProblemSolution
"Invalid username or password"Reset the password via reset_admin.php (delete after)
Page just reloads, no errorCheck that the target dashboard file exists
Login page shows blankCheck PHP error log at C:\xampp\apache\logs\error.log
"Access denied" after loginVerify your role in users table

Image / Photo Issues

ProblemSolution
Photo doesn't showCheck file exists in uploads/members/ and has size > 0
Upload failsEnsure folder uploads/members/ exists and is writable
"Failed to open stream"File path is wrong — verify with dir

Database Issues

ProblemSolution
"Database connection failed"Start MySQL in XAMPP Control Panel
"Table doesn't exist"Import database.sql in phpMyAdmin
"Duplicate column"Safe to ignore — column already exists

Header Already Sent Warning

This means HTML was output before a redirect. Fix:

  • All form processing and redirects must happen before including _layout.php
  • Move if ($_SERVER['REQUEST_METHOD'] === 'POST') { ... redirect(); } to the top of the file

System Slow or Unresponsive

  • Check disk space in Admin → Dashboard
  • Clear old backups (Admin → Backups)
  • Clear old logs (Admin → Activity Logs → Clean Old)
  • Restart Apache and MySQL in XAMPP

Time / Date Wrong

  1. Admin → Settings
  2. Set timezone to Africa/Accra
  3. Save
